# Retail Sales Dashboard

Power BI project focused on **retail sales performance, KPI visibility and business exploration**.

## Deliverables

- `Dashboard de Vendas.pbix` — interactive Power BI source.
- `Sales Dashboard.pdf` — static export for quick review.

## Analytical focus

The project demonstrates a BI serving layer for retail data, emphasizing:

- sales-performance visibility;
- consistent filtering and dimensional navigation;
- KPI-oriented presentation;
- trend and exception analysis;
- separation between analytical metrics and raw source fields.

## How to review

Open the PDF for a static preview. Download the `.pbix` file to explore the interactive report in Power BI Desktop.
