# Orders & Requests Analysis

Power BI project focused on operational visibility for **orders and requests**.

## Deliverables

- `Projeto_PedroVelame.pbix` — Power BI source file from the original project.
- `Análisedepedidos_PEDRO_VELAME (1).pdf` — exported dashboard/report for quick review without Power BI Desktop.

> Some binary filenames preserve the original historical naming. The current author name is **Harrison Grant Vail**.

## Analytical focus

This project is presented as an example of translating operational records into a decision-oriented BI layer. The design intent is to make request/order activity easier to inspect through consistent dimensions, filters and summary indicators.

## How to review

For a quick static review, open the PDF export. For the interactive model, download the `.pbix` file and open it with Power BI Desktop.

This dashboard is the serving/visualization side of my broader data portfolio. For pipeline, transformation, data-quality and lakehouse examples, see [`harrisvailvelame/pedrohvel`](https://github.com/harrisvailvelame/pedrohvel).
