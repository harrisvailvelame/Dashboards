# Orders & Requests Analysis

Power BI project focused on operational visibility for **orders and requests**.

## Deliverables

- `orders_requests_analysis.pbix` — interactive Power BI source.
- `orders_requests_analysis.pdf` — static export for quick review.

## Analytical focus

This project demonstrates how operational records can be translated into a decision-oriented BI layer with consistent dimensions, filters and summary indicators.

## How to review

Open the PDF for a quick static review. Download the `.pbix` file and open it in Power BI Desktop for the interactive model.

This dashboard represents the serving/visualization side of my broader data portfolio. For ingestion, transformation, data quality and lakehouse examples, see [`harrisvailvelame/pedrohvel`](https://github.com/harrisvailvelame/pedrohvel).
