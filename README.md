## Analytical approach

- Define the business grain before visualization
- Separate raw fields from business metrics
- Prefer a small set of decision-oriented KPIs
- Keep filters and dimensions consistent across views
- Use visual hierarchy to emphasize exceptions and trends
- Treat dashboards as the serving layer of a broader data pipeline
