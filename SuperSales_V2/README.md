# SuperSales V2

![Dashboard preview](./dashboard_preview.png)

Revised Power BI iteration of the Superstore sales analysis, focused on **sales, profit, category performance, geography, products, shipping and order trends**.

## Deliverables

- `supersales_v2.pbix` — interactive Power BI source.
- `supersales_v2.pdf` — static dashboard export.
- `dashboard_preview.png` — visual preview.

## Analytical scope

The dashboard explores:

- time evolution of sales and profit;
- city-level profitability;
- category and subcategory performance;
- high-volume products;
- profit/value relationships;
- shipping-mode comparisons;
- order-volume trends.

## Why V2 exists

This version is kept separately to show iteration in report design and analytical presentation rather than treating a dashboard as a one-off artifact.

## How to review

Use the PNG or PDF for a quick visual review. Open the `.pbix` file in Power BI Desktop for the interactive experience.
